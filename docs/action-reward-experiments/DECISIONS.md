## 本轮判断

最明确的正向信号是 **TextWorld × Qwen3.5**：相对五候选随机选择，成功率从 46% 升至 70%，配对任务 bootstrap 区间为 +10 至 +38 个百分点；补充任务组 bootstrap 仍为正。

其余五组相对五候选随机选择的点估计均为正，但区间包含或触及零。当前证据不足以声称跨环境、跨 seed 的稳定提升。

WebShop 原生 reward 也有正向点估计：Qwen3.5 为 0.5303 → 0.5893，Qwen3-VL 为 0.6146 → 0.6542；对应区间均包含零。表中点估计和置信区间应一起引用。

## 需要拆解的限制

| 观察 | 本轮证据 | 对后续的影响 |
|---|---|---|
| Qwen3.5 截断较多 | TextWorld 的选中动作截断率：random5 35.7%，Sol 10.8%；THOR 的 Sol 候选池中 31.4% 五个候选全部截断 | 不能把所有增益归为语义判断；需区分规避截断与动作质量。任何 token 上限变更另建实验版本 |
| Qwen3 / Qwen3-VL 候选重复 | Sol 轨迹中五动作相同的池比例：TextWorld Qwen3 74.6%，THOR Qwen3-VL 92.9%，WebShop Qwen3-VL 71.8% | 部分状态几乎没有选择空间；先检查可选动作差异，再决定标注规模 |
| THOR 多数 episode 达步数上限 | Qwen3.5 + Sol 为 82%，Qwen3-VL + Sol 为 86% | 分析重复动作、目标识别与官方控制器执行结果；高层选择结论不外推为端到端视觉控制能力 |
| 单 seed、50 个预留任务 | 任务 bootstrap 不估计跨运行 seed 波动；ALFWorld 部分任务同组相关 | 目前定位为探索性 pilot，补充按组重采样；不使用正式测试集来调协议 |

上述候选诊断来自各策略实际访问的状态，不是反事实 rollout 或 oracle 动作质量，不能直接作为因果分解。
